# Reproducibility guide

## Publication-facing GitHub repository

This repository keeps the lightweight materials needed to review and validate the manuscript's numerical claims: schema, result tables, metadata, validation code, and the downstream analysis script. The full 17,779-row co-simulation dataset, 10,000-row synthetic reference, 43 per-run CSVs, 43 YAML manifests, exact manuscript figures, source co-simulation pipeline, and representative provenance chain are packaged in the companion Zenodo v2.0.0 artifact at https://doi.org/10.5281/zenodo.22709680.

## Environment and repository validation

Use Python 3.12 and the pinned packages in `requirements.txt`:

```bash
python -m pip install -r requirements.txt
python analysis/validate_repository.py
```

The validator checks the repository structure, telemetry schema, citation/Zenodo metadata consistency, dual-license notices, key result-table contents, creator count/order, and documented local script paths.

## Full numerical reproduction

After downloading the companion Zenodo artifact, place the aggregate datasets at:

```text
data/synthetic_reference/drone_network_telemetry_dataset.csv
data/cosimulation/drone_network_telemetry_cosim.csv
```

Then run:

```bash
python analysis/reproduce_manuscript_analysis.py
```

The script regenerates matched five-fold mission/run-group validation for RF and HGB, zero-shot synthetic↔co-simulation transfer for RF and HGB, and all-row/normal-only KS distribution-shift diagnostics. Regenerated tables are written to `analysis_outputs/`.

The archived `results/window_level_model_metrics.csv` is the secondary 70/30 window-level reference used in Section 4.4 of the final manuscript. It is preserved from the original co-simulation model report rather than regenerated by the group-wise script.

Final manuscript mapping:

- `results/fair_groupwise_comparison.csv` -> Table 7 / Fig. 6.
- `results/cross_domain_transfer_results.csv` -> Table 8 / Fig. 7.
- `results/distribution_shift_results.csv` -> Fig. 8.
- `results/window_level_model_metrics.csv` -> Section 4.4.
- Zenodo `figures/manuscript/` -> Figs. 1-9.

## Source co-simulation boundary

The original environment used Ubuntu 24.04, ROS 2 Jazzy, Gazebo Sim 8.11.0, PX4 SITL/x500, OMNeT++ 6.0.1, INET 4.5, and Simu5G 1.2.2. Third-party simulator installations and large regenerable `.vec`/`.mcap` intermediates are not redistributed. Source-level reconstruction material is in the companion archival package; exact recreation of every simulator run also requires the external simulator stack and regeneration or local availability of required flight pose traces.
